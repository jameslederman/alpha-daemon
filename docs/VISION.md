# AlphaDaemon Vision

AlphaDaemon is a persistent, evidence-grounded, and auditable investment
research system. It develops and updates theses, reasons across heterogeneous
financial information, incorporates portfolio context, and can eventually
propose or execute trades under deterministic controls.

## Principles

- Prefer evidence and provenance to unsupported conclusions.
- Make point-in-time research reproducible.
- Add agent specialization only when it provides measurable value.
- Let models propose actions; use deterministic systems to enforce risk.
- Require each capability to improve research quality, reliability, or usability.
- Complete research and paper-trading validation before autonomous execution.

## Non-goals

- A generic financial chatbot
- Interface polish before the research kernel is reliable
- Multi-agent debate without differentiated data, methods, or authority
- Data providers without an identified information gap
- Autonomous live trading before evaluation and guardrails
